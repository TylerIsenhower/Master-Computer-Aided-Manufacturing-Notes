# Flexible Manufacturing Systems (FMS)

#mmet380 #ch5 #concept

## In Plain English

An FMS is the "Holy Grail" of manufacturing. It combines the speed of an automated production line with the flexibility of a single CNC machine. Instead of a person walking between machines, a central robot or an automated vehicle (AGV) moves parts between machining centers. A central computer coordinates everything. An FMS can make a mix of different parts at the same time and can keep running even if one machine breaks down—the computer just reroutes the parts to a different machine.

## FMS Components

A true FMS requires four integrated parts:

1. **Workstations:** High-end CNC machining centers with Automatic Tool Changers (ATC) and storage.
2. **Material Handling / Storage:** Robots or conveyors that can move parts independently between any two stations. It must handle different part geometries and have temporary storage.
3. **Computer Control System:** A central "brain" that schedules the parts, and microcomputers that control each individual machine.
4. **Human Assistance:** While highly automated, humans are still needed for maintenance, NC programming, and loading/unloading parts onto the system.

## Key Capabilities

- **Mixed Mode:** Can produce a mix of different parts simultaneously.
- **Batch Mode:** Can switch between different batches of parts with zero setup time.
- **Error Recovery:** If one machine goes down, the system can stay operational by rerouting parts.
- **Scalability:** New parts can be added to the system simply by loading new NC programs.
